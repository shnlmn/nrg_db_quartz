# Aided Language Stimulation

## Summary

Aided language stimulation is the practice of communication partners modeling language directly on an AAC user's own system throughout the day, rather than relying solely on periodic therapy sessions. Everyone around an AAC user — educators, paraprofessionals, parents, and peers — can and should model the system, since AAC users need to see other people using AAC to learn it.

## Key claims

- Related-services therapy a few times per week will not make an AAC user successful in the classroom; classroom teachers and paraprofessionals must model language on the AAC system throughout the day. [[raw/AAC_and_Autism_Tip_Sheet_Edu.extracted.md]]
- AAC users need to see other people using AAC; everyone (educators, paraprofessionals, parents, peers) can teach the student collaboratively. [[raw/AAC_and_Autism_Tip_Sheet_Edu.extracted.md]]

## Component strategies

| Strategy | Guidance |
|---|---|
| Wait time | Allow twice the expected time so the AAC user can process and respond |
| Model — variety of words | Model both core words ("my," "want," "go") and fringe words; core words are used far more often than topic-specific fringe words |
| Model — attribute meaning | Assign words to non-verbal behavior (e.g., "I see you moving away, you do not like that") |
| Model — self-talk | Narrate the modeler's own thinking aloud while searching the AAC system, demonstrating that mistakes are part of learning |
| Model — parallel talk | Narrate aloud what the AAC user is doing, giving them language for their own activity |
| Comment | Comment on the AAC user's actions or surroundings with no expectation of a response; favor comments over questions |
| Recast/Expand | Take the AAC user's utterance and return an enhanced or contrasting version by changing sentence components |
| Prompt | Give the least prompting needed, with adequate wait time first; see [[prompt-hierarchy]] |
