# Core Vocabulary

## Summary

Core vocabulary is the small set of high-frequency, cross-context words (pronouns, common verbs, prepositions, question words, negation, descriptors, and social words) that make up the reusable backbone of an AAC vocabulary system, as distinct from context-specific [[picture-exchange-communication-system|fringe vocabulary]]. Because core words recur across settings and topics, AAC implementations such as [[communication-boards]] and [[project-core]]'s Universal Core vocabulary prioritize giving users constant access to them alongside setting-specific fringe words.

## Key claims

- A core word list groups words by grammatical/functional category rather than by topic, reflecting their use across any setting or activity rather than one specific context. [[raw/Core Words.md]]
- Core word lists commonly include pronouns, core verbs, helping/modal verbs, prepositions, question words, negation, descriptive/quantity words, social/interjection words, time/sequence words, location/demonstrative words, conjunctions, and articles. [[raw/Core Words.md]]
