# AAC Backup Board Audit Checklist

> [!info] Promoted from a query. Verify against source pages before citing.

## Summary

A four-point checklist for auditing any facilitation note that adds a backup [[communication-boards|communication board]] to a research or visit protocol, cross-checked against [[core-vocabulary]], [[communication-boards]], [[aided-language-stimulation]], and [[prompt-hierarchy]]. Applied once already to `pages/promoted/q-built-environment-questions-autistic-adults.md`, where it caught a non-canonical word choice and three unaddressed gaps.

## Checklist

1. **Word-list alignment** — every backup-board word must match a canonical [[core-vocabulary]] category entry (or be an explicitly-tagged fringe word, see point 2). Words that sound plausible but aren't in the list (e.g. "leave", "loud") should be swapped for the matching core word ("go") or dropped if no core/fringe equivalent exists.
2. **Core + fringe combo** — per [[communication-boards]], symbols should represent both core vocabulary and setting-specific fringe vocabulary. A backup board listing only core words is incomplete; add fringe words specific to the visit setting (e.g. for a library: toilet, book, exit).
3. **Modeling guidance** — per [[aided-language-stimulation]], an AAC board only works if communication partners model it throughout the interaction, not merely have it present. A facilitation note that says "have board on hand" without instructing the facilitator to point to/model it during the visit has a gap.
4. **Prompt-hierarchy note** — per [[prompt-hierarchy]], if a participant hesitates before pointing, facilitators should apply wait-time first, then indirect cues, with physical prompting last and only with consent. Facilitation notes that don't mention this risk facilitators over-helping (reaching in) too early.
