# Adult Adolescent Sensory Profile

## Summary

The Adult/Adolescent Sensory Profile (AASP) is a standardized formal assessment tool used to measure [[sensory-processing-dysfunction]] and [[sensory-preferences]] in adolescents and adults. It provides quantitative data on sensory processing patterns across multiple sensory modalities.

## Key claims

- Formal assessment tool referenced in [[sensory-assessment-neurodevelopmental]] protocols [[raw/NAIT-Guide-to-Assessment-of-Sensory-Preferences-in-Adults-2022.extracted.md]]
- Used clinically as one of the primary options for structured sensory assessment in adult [[sensory-processing-autism]] and [[sensory-processing-adhd]] evaluation
- Available through Pearson Clinical (pearsonclinical.co.uk)
- Complements informal questionnaires and occupational therapy observation [[raw/NAIT-Guide-to-Assessment-of-Sensory-Preferences-in-Adults-2022.extracted.md]]
